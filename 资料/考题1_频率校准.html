考题一：频率校准

只考一件事：MCU 在 SCK 上做出的 128 µs 高电平，H6 芯片认不认。

记住三件事

128 µs

命令靠 SCK 高电平的宽度区分。允许 ±5%，即 121.6～134.4 µs。

7C～84

两颗芯片回的低 8 位都在这个范围才算过。最多试 128 次。

20 ms

成功后照手册等 20 ms 再往下走。只在开机跑一次。

怎么跑这一关

  1. git pull，Keil Rebuild，0 Error 后烧录。
  2. 插 USB，运行 python tools/hid_log.py，只看 EXAM1 那一行。
  3. 正式考，应该看到： 
    EXAM1 CAL ok=1 n=.. R=00:7C~84 L=00:7C~84 width=128
  4. 对照实验：button.c 里把 HALL_EXAM1_BAD_WIDTH 改成 1，重新烧录，应该看到： 
    EXAM1 CAL ok=0 n=128 R=00:00 L=00:00 width=145
    看完改回 0。

两次都对，这一关才算过。对照实验证明这道题真的能判出错。如果 145 µs 也显示 ok=1，那 128 µs 的“通过”就不可信。

采样值乱跳、右键乱触发是后面几关的事，现在不用管。
